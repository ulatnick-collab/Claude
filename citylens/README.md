# Город-лупа

Детективная игра для iPhone (PWA): огромная нарисованная карта города, сотни крошечных людей и пять дел.
Нужно приближать карту, идти по следу героя и раскрывать преступления. Вся графика, карта и дела оригинальные.

## Запуск на iPhone

PWA — это обычный статический сайт, поэтому выложите папку `citylens/` на любой хостинг с HTTPS
(GitHub Pages, Netlify, Cloudflare Pages, Vercel и т. п.). Затем на iPhone:

1. Откройте ссылку в Safari.
2. Нажмите «Поделиться» → «На экран “Домой”».
3. Игра запустится как приложение без адресной строки и будет работать офлайн.

Локально: `cd citylens && python3 -m http.server 8000`, затем откройте `http://<IP компьютера>:8000` на телефоне
(офлайн-режим и установка требуют HTTPS, кроме `localhost`).

## Устройство

| Файл | Назначение |
|---|---|
| `js/figures.js` | SVG-человечки: шляпы, одежда, предметы |
| `js/city.js` | карта 2400×1600: дороги, кварталы, здания, 300 человек толпы |
| `js/cases.js` | герои и дела (сцены, подсказки, ответы) |
| `js/app.js` | жесты (перетаскивание, щипок), экраны, подсказки, прогресс (localStorage) |
| `sw.js`, `manifest.webmanifest` | офлайн-режим и установка на экран «Домой» |

## Как добавить дело

В `js/cases.js` добавьте героев в `CAST` и запись в `CASES`: `story`, `question`, `kind` (`tap` — коснуться места на карте,
`choice` — выбрать вариант), `scenes` (где и в каком виде герой появляется на карте), `hints` и `solution`.
Толпа автоматически не повторяет сочетание «шляпа + цвет» ни у одного героя.
